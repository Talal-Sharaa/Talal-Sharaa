## About me

I'm a software engineer focused on **C#/.NET backend engineering**, particularly **messaging, integrations, performance, and troubleshooting**. My professional work includes capital-markets systems, where services communicate using technologies such as **Kafka, FIX, IBM MQ, REST, and TCP/UDP**.

I enjoy problems where the symptom and the cause are far apart: tracing behavior through application code, operating systems, networks, and databases until I understand what is actually happening. I prefer **measurements, reproducible tests, and explicit trade-offs** over confident guesses.

I also build across the stack when the problem calls for it. Outside work, I build and operate independent projects, including [Fihris](https://fihris.page), a bilingual book-discovery website.

> I care about making software observable, maintainable, and safe to change.

## Selected projects

### 📚 [Fihris — bilingual book discovery](https://fihris.page)

An independent Arabic/English book-discovery website built with **Next.js and TypeScript**. It helps readers find book listings across participating bookstores and follow links to the stores. It's a discovery tool, not a marketplace.

**Engineering interests:** external-system integration, reliability, performance, and operating a live product.

### 🧪 [Claude Code Engineering Handbook](https://github.com/Talal-Sharaa/claude-code-engineering-handbook)

A public engineering handbook with practical templates, helper scripts, tests, and a validation record that distinguishes **what was checked from what remains unverified**.

**Engineering interests:** reproducibility, explicit evidence, safe automation, and developer workflows.

### 🪟 [WinAdvisor](https://github.com/Talal-Sharaa/WinAdvisor)

Windows diagnostics, maintenance, and cleanup orchestration. Inspects a system before recommending actions, with an emphasis on **read-only analysis, explicit approval, risk classification, and rollback**.

**Stack:** PowerShell · Windows · Diagnostics

### 🎬 [MoviesWorkshop](https://github.com/Talal-Sharaa/MoviesWorkshop)

A local FFmpeg-based video workflow for subtitle rendering and size-aware compression, with output validation and an interactive preview loop.

**Stack:** Python · FFmpeg · CLI
